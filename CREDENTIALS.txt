---------------------------------------------------
INSTALLATION STEPS FOR NEW COMPUTER
---------------------------------------------------

1. INSTALL THE ADDON:
   - Copy the entire 'styleengine' folder to:
     Windows: C:\Users\[YourName]\AppData\Roaming\Blender Foundation\Blender\[Version]\scripts\addons\
     macOS:   ~/Library/Application Support/Blender/[Version]/scripts/addons/
     Linux:   ~/.config/blender/[Version]/scripts/addons/

2. ENABLE IN BLENDER:
   - Open Blender
   - Edit → Preferences → Add-ons
   - Search for "Style Engine"
   - Check the box to enable it

3. CONFIGURE CREDENTIALS:
   - Expand the Style Engine preferences
   - Paste your RunComfy API Token
   - Paste your RunComfy User ID
   - Verify the Deployment ID matches: 1c6fa9a6-f60a-4e89-863d-40b03ad2564e

4. TEST CONNECTION:
   - Click "Test Connection" button
   - Should see: "✓ Connection test successful!"

5. READY TO USE:
   - Open 3D View → N key → Style Engine tab
   - Click "Setup Workspace"
   - Start generating!


---------------------------------------------------
WORKFLOW MODES
---------------------------------------------------

SDXL Mode:
- Default mode for general AI generation
- Uses prompt + depth/silhouette control

IPAdapter Mode:
- Uses a reference image for style transfer
- Enable in the "IPAdapter Settings" section
- Choose reference image and set strength (0.0-5.0)
- Weight type is hardcoded as "style transfer" in deployed workflow

IMPORTANT NOTES

---------------------------------------------------
TROUBLESHOOTING
---------------------------------------------------

If "Test Connection" fails:
- Check your API token is correct (no spaces)
- Check your User ID is correct
- Verify internet connection
- Check Blender console (Window → Toggle System Console)

If generation fails:
- Check the Blender console for detailed error messages
- Verify the Deployment ID is correct
- Make sure you have API credits on RunComfy account


---------------------------------------------------
WHERE TO FIND YOUR RUNCOMFY CREDENTIALS
---------------------------------------------------

1. Go to: https://www.runcomfy.com/
2. Log in to your account
3. Navigate to Settings or API section
4. Copy your API Token
5. Copy your User ID
6. Paste them into the Blender addon preferences
