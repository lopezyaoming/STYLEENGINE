================================================================================
2. GLOBAL STRENGTH SLIDERS - REMAPPED
================================================================================

UI SLIDER RANGE CHANGED:
------------------------
BEFORE: 0.0 ──────────────────────────────────> 5.0
         [──────────────────────────────────────]

AFTER:  0.0 ─────────> 1.0
         [──────────────]

What user sees: Slider from 0.0 to 1.0 (more intuitive!)


BEHIND THE SCENES (Automatic):
-------------------------------
UI Value → Multiplied by 1.5 → Sent to Workflow

Examples:
┌──────────┬─────────────────┐
│ UI Shows │ Workflow Gets   │
├──────────┼─────────────────┤
│   0.00   │      0.00       │
│   0.25   │      0.375      │
│   0.50   │      0.75       │
│   0.75   │      1.125      │
│   1.00   │      1.50       │
└──────────┴─────────────────┘

Your example: UI 0.75 → Workflow 1.12 ✓


WHY THIS IS BETTER:
-------------------
✓ 0-1 scale is industry standard (like opacity, alpha, etc.)
✓ More intuitive for artists
✓ Old 5.0 max was unnecessarily high (caused over-aggressive styling)
✓ Easier to find good values (most work in 0.3-0.8 range)
✓ Behind-the-scenes multiplier gives optimal 0-1.5 range for IPAdapter
