1. INTRODUCTION
================================================================================

1.1 WHAT IS STYLE ENGINE?
--------------------------

Style Engine is a Blender addon that integrates AI image generation directly 
into your 3D modeling workflow. It allows you to:

- Generate AI images from your 3D renders in real-time
- Project AI textures onto your 3D objects
- Navigate through generation history
- Mix different AI styles in a single scene
- Control the balance between render and AI generation

Think of it as a bridge between your 3D work and AI generation, enabling 
iterative workflows where you can quickly explore visual styles, apply 
textures, and build complex scenes with multiple AI generations.


1.2 KEY FEATURES
-----------------

GENERATION FEATURES:
• Three backend modes (GCS, RunComfy, Local)
• img2img workflow with texture control
• ControlNet integration (Canny edges + Depth maps)
• IPAdapter with 15 reference image slots
• Real-time generation with progress tracking

WORKFLOW FEATURES:
• Generation browser (navigate through history)
• Texture projection (project AI onto objects)
• Archival materials (freeze textures in time)
• Iterative remixing (mix old and new generations)
• Per-project library (automatic organization)

INTERFACE FEATURES:
• Pie menu (Alt+W) for quick access
• Visualization switcher (Combined/Silhouette/Depth)
• Render quality selector (Fast/Detailed)
• Reference image thumbnails
• Progress and status indicators


1.3 SYSTEM REQUIREMENTS
------------------------

MINIMUM:
• Blender 4.2 or newer
• Windows 10/11, macOS 10.15+, or Linux
• 8GB RAM
• Internet connection (for cloud backends)

RECOMMENDED:

• Dedicated GPU (for EEVEE rendering)

BACKEND REQUIREMENTS:
• GCS Mode: Google Cloud ComfyUI instance

• Local Mode: Local ComfyUI installation (future)

2. INSTALLATION
================================================================================

2.1 FIRST-TIME INSTALLATION
----------------------------

STEP 1: Download
• Obtain styleengine.zip (364 KB)
• Verify file integrity (should be ~364 KB)

STEP 2: Install in Blender
1. Open Blender 4.2 or newer
2. Go to: Edit → Preferences → Add-ons
3. Click "Install from Disk..." button (top right)
4. Navigate to styleengine.zip
5. Click "Install Add-on"
6. Find "Style Engine" in the list
7. Check the checkbox to enable it

STEP 3: Verify Installation
• Look for console output: "[Style Engine] Initial path detection"
• Check for: "Style Engine" tab in 3D viewport sidebar (press N)
• Open pie menu: Alt+W (should show Style Engine menu)

STEP 4: Configure Backend
• Edit → Preferences → Add-ons → Style Engine
• Choose backend mode (GCS or RunComfy)
• Enter credentials/server URL
• Click "Test Connection"


2.2 UPDATING FROM PREVIOUS VERSION
-----------------------------------

IMPORTANT: Always uninstall old version first!

STEP 1: Uninstall Old Version
1. Edit → Preferences → Add-ons
2. Find "Style Engine" in the list
3. Click the X button to remove
4. **RESTART BLENDER** (critical!)

STEP 2: Install New Version
1. Follow "First-Time Installation" steps above
2. Your settings will be preserved (stored in Blender preferences)
3. Your project libraries remain intact (in project folders)

STEP 3: Verify Update
• Check version in addon preferences
• Test basic generation
• Check that old projects still load correctly


2.3 UNINSTALLATION
-------------------

STEP 1: Disable Addon
1. Edit → Preferences → Add-ons
2. Find "Style Engine"
3. Uncheck the checkbox

STEP 2: Remove Addon
1. Click the X button
2. Restart Blender

STEP 3: Clean Up (Optional)
• Delete project libraries (YourProject_styleengine folders)
• Clear system temp: C:\Users\You\AppData\Local\Temp\blender_styleengine\
• Remove credentials file (if used)

NOTE: Project libraries contain all your generated images. Only delete if 
you're sure you don't need them!


2.4 TROUBLESHOOTING INSTALLATION
---------------------------------

ISSUE: "Add-on not loaded" error
SOLUTION:
• Make sure you uninstalled old version
• Restart Blender completely
• Try installing again
• Check console for specific error messages

ISSUE: "Module not found" errors
SOLUTION:
• Verify styleengine.zip is not corrupted
• Re-download the addon
• Make sure you're using Blender 4.2+

ISSUE: Addon checkbox grayed out
SOLUTION:
• Check console for Python errors
• Verify Blender version (must be 4.2+)
• Try installing in a fresh Blender install

ISSUE: "SyntaxError" or "IndentationError"
SOLUTION:
• This indicates a corrupted installation
• Uninstall completely
• Restart Blender
• Reinstall from fresh styleengine.zip

3. GETTING STARTED
================================================================================

3.1 BACKEND CONFIGURATION
--------------------------

Before you can generate images, you need to configure a backend.

OPTION A: GCS MODE (Self-Hosted ComfyUI)
1. Edit → Preferences → Add-ons → Style Engine
2. Backend Mode: Select "Self-Hosted ComfyUI"
3. Server URL: Enter your ComfyUI URL (e.g., http://34.19.119.45:8188)
4. Click "Test Server Connection"
5. Wait for: "✅ Server is healthy and ready!"

OPTION B: RUNCOMFY MODE (Serverless Cloud)
1. Edit → Preferences → Add-ons → Style Engine
2. Backend Mode: Select "RunComfy Cloud"
3. Enter API Token and User ID
4. Click "Test Connection"
5. Wait for: "✅ Connection successful!"

WHICH TO CHOOSE?
• GCS: Your own server, full control, requires setup
• RunComfy: Managed service, easy setup, costs per use


3.2 WORKSPACE SETUP
--------------------

Every project starts with workspace setup.

STEP 1: Open or Create .blend File
• File → New (or open existing project)
• RECOMMENDED: Save your .blend file first
  (This enables per-project library immediately)

STEP 2: Setup Workspace
• Press Alt+W (pie menu)
• Click "Setup Workspace" (LEFT section)
• OR: Press N → Style Engine tab → (if visible)

WHAT HAPPENS:
• Creates "ai_camera" in your scene
• Positions camera at your current view
• Creates black placeholder image (1024x1024)
• Sets up workspace layout
• Creates prompt text editor
• Initializes project library (if .blend saved)

CONSOLE OUTPUT:
[Style Engine] 🆔 Session ID: 20251123_143022_abc123
[Style Engine] 🔒 Temp directory locked: C:\Projects\MyProject\temp\ai_vision
[Style Engine] 🖤 Created fresh black placeholder: 1024x1024
[Style Engine] Created new ai_camera
[Style Engine] ✓ Loaded workspace template successfully


3.3 YOUR FIRST GENERATION
--------------------------

STEP 1: Write a Prompt
• Find the text editor in your workspace
• Type your prompt (e.g., "futuristic city at sunset")
• OR: Use a template (see section 7.2)

STEP 2: Adjust Settings (Optional)
• Press Alt+W → BOTTOM section
• Adjust Silhouette: 0.5 (default)
• Adjust Depth: 0.5 (default)
• Adjust Influence: 0.25 (default - good balance)
• Adjust Steps: 15-30 (15 is fast, 30 is quality)

STEP 3: Generate
• Press Alt+W
• Click "Generate Image" (BOTTOM section)
• Wait for generation (15-30 seconds)

STEP 4: View Result
• Camera view updates automatically
• Image saved to generations/ folder
• Console shows: "✅ Generation saved to library"

CONGRATULATIONS! You've generated your first AI image!

4. BACKEND MODES
================================================================================

4.1 GCS MODE (Google Cloud Services)
-------------------------------------

WHAT IT IS:
Direct connection to a self-hosted ComfyUI instance running on Google Cloud
(or any cloud provider, or localhost).

SETUP:
1. Have a ComfyUI server running (e.g., on GCS T4 instance)
2. Note the IP and port (e.g., http://34.19.119.45:8188)
3. In Style Engine preferences:
   • Backend Mode: "Self-Hosted ComfyUI"
   • Server URL: http://34.19.119.45:8188
   • Click "Test Server Connection"

FEATURES:
• Direct HTTP connection (no OAuth2)
• Full control over server
• Can use any ComfyUI workflow
• Preview images (Canny/Depth) available

WORKFLOW:
StyleEngineTexture.json (img2img with texture control)

BEST FOR:
• Teams with cloud infrastructure
• Projects requiring full control
• High-volume generation
• Custom workflow needs


4.2 RUNCOMFY MODE (Serverless Cloud)
-------------------------------------

WHAT IT IS:
Managed serverless ComfyUI service. No server management required.

SETUP:
1. Get RunComfy API credentials (token + user ID)
2. In Style Engine preferences:
   • Backend Mode: "RunComfy Cloud"
   • Enter API Token
   • Enter User ID
   • Click "Test Connection"

FEATURES:
• Automatic scaling
• No server maintenance
• Pay per generation
• Managed infrastructure

WORKFLOW:
SDXLREF.json (SDXL with reference images)

BEST FOR:
• Quick setup
• No infrastructure management
• Pay-as-you-go pricing
• Managed service preference


4.3 LOCAL MODE (Future)
------------------------

WHAT IT IS:
Direct connection to ComfyUI running on your local machine.

STATUS: Planned for future release

WILL INCLUDE:
• Localhost connection (127.0.0.1:8188)
• No internet required
• Full privacy
• Free to use (your hardware)


4.4 CHOOSING THE RIGHT BACKEND
-------------------------------

CHOOSE GCS IF:
• You have Google Cloud credits
• You want full control
• You need custom workflows
• You're working with a team

CHOOSE RUNCOMFY IF:
• You want quick setup
• You don't want to manage servers
• You're okay with pay-per-use
• You want managed infrastructure

CHOOSE LOCAL IF: (Future)
• You have powerful local hardware
• You want complete privacy
• You want zero cloud costs
• You're okay with slower generation

5. CORE WORKFLOWS
================================================================================

5.1 BASIC GENERATION WORKFLOW
------------------------------

PURPOSE: Generate AI images from your 3D scene

STEPS:
1. Setup workspace (Alt+W → Setup)
2. Model your scene in left viewport
3. Write prompt in text editor
4. Press Alt+W → Generate Image
5. Wait for generation (~15-30 seconds)
6. View result in camera view

TIPS:
• Start with default settings (Influence 0.25, Steps 15)
• Use Fast render quality for quick iterations
• Save your .blend file to enable project library
• Generate multiple variations before projecting


5.2 IMG2IMG WORKFLOW (Texture Control)
---------------------------------------

PURPOSE: Control how much of your render is kept vs AI generation

THE INFLUENCE SLIDER:
Located in: Alt+W → BOTTOM → Influences → Influence

VALUE GUIDE:
• 1.0 = Keep 100% of render (minimal AI, just ControlNet)
• 0.75 = Keep 75% of render (subtle AI enhancement)
• 0.5 = 50/50 blend (balanced)
• 0.25 = Keep 25% of render (good transformation) ← DEFAULT
• 0.0 = 0% render (full AI generation)

WORKFLOW EXAMPLE:
1. Model detailed scene with materials
2. Set Influence to 0.25 (default)
3. Set Render Quality to "Detailed" (EEVEE)
4. Generate
5. Result: AI transforms your render while keeping structure

WHEN TO USE HIGH INFLUENCE (0.7-1.0):
• Polishing final renders
• Subtle lighting adjustments
• Client work requiring approval
• Maintaining exact geometry

WHEN TO USE LOW INFLUENCE (0.0-0.3):
• Creative exploration
• Style transformation
• Concept art variations
• Dramatic changes


5.3 TEXTURE PROJECTION WORKFLOW
--------------------------------

PURPOSE: Apply AI-generated textures to your 3D objects

BASIC STEPS:
1. Generate AI image
2. Position your viewport to desired projection angle
3. Select object(s) to project onto
4. Alt+W → Project on Object (TOP)
5. Texture projects from your current view

WHAT HAPPENS:
• Creates archival material (iteration_000, iteration_001, etc.)
• Creates archival image (iteration_000.png)
• Assigns material to selected objects
• Projects UVs from your active view
• Saves texture to iterations/ folder

TIPS:
• Position view carefully before projecting
• Works with single or multiple objects
• Each projection creates unique material
• Textures frozen in time (won't change with new generations)


5.4 ITERATIVE REMIXING WORKFLOW
--------------------------------

PURPOSE: Mix different AI generations on different objects

ADVANCED WORKFLOW:
1. Generate 3-5 different style variations
   • Photorealistic
   • Concept art
   • Painterly
   • Sketch
   • etc.

2. Navigate to first generation
   • Alt+W → RIGHT → Click ◀ (go back)
   • Camera shows first generation

3. Select objects for this style
   • Select Cube, Sphere, etc.

4. Project on Object
   • Alt+W → Project on Object
   • Objects get first generation texture

5. Navigate to second generation
   • Alt+W → RIGHT → Click ▶ (go forward)
   • Camera shows second generation

6. Select different objects
   • Select Monkey, Torus, etc.

7. Project on Object
   • Alt+W → Project on Object
   • Objects get second generation texture

8. Repeat for more generations
   • Navigate ◀ ▶
   • Select objects
   • Project

RESULT: Multiple AI styles in one scene!

----------------------------

FEATURES:
• Generate Image button (big, prominent)
• Influence sliders (Silhouette, Depth, Influence)
• Steps slider
• Autogenerate toggle
• Render Quality selector (Fast/Detailed)

GENERATE IMAGE BUTTON:
• Starts AI generation process
• Uses current prompt and settings
• Saves to generations/ folder
• Updates camera view when complete

INFLUENCE SLIDERS:
• Silhouette: Controls Canny edge strength (0.0-1.0)
  Default: 0.5
  
• Depth: Controls depth map strength (0.0-1.0)
  Default: 0.5
  
• Influence: Controls render preservation (0.0-1.0)
  Default: 0.25 (75% AI, 25% render)

STEPS:
• Number of sampling steps (15-30)
• More steps = higher quality, longer time
• Default: 15 (good balance)

AUTOGENERATE:
• Toggle continuous generation
• Generates new image every ~30 seconds
• Useful for rapid iteration

RENDER QUALITY:
• Fast: Workbench render (~0.1s)
• Detailed: EEVEE render (~1-3s)
• Choose based on Influence value:
  - High Influence (0.7+) → Use Detailed
  - Low Influence (0.0-0.3) → Use Fast

7.1 PROMPT SYSTEM
------------------

WHERE TO WRITE:

7.2 PROMPT BUILDER (Templates)
-------------------------------

WHAT IT IS:
Structured prompt system using tags for organized prompting.

HOW TO ENABLE:
1. In UI panel (press N → Style Engine)
2. Find "Prompt Settings"
3. Check "Enable Prompt Builder"

AVAILABLE TEMPLATES:
• Empty: Blank slate for custom prompts
• Vizdev: Concept art / visual development
• Photorealistic: Professional photography

TEMPLATE FORMAT:
# Subject:
your subject here

# Style:
art style, medium

# Details:
specific details

# Environment:
background, setting

# Mood:
atmosphere, feeling

# Camera:
angle, perspective

# Lighting:
lighting conditions

# Negative Prompt:
things to avoid

HOW TO USE:
1. Enable Prompt Builder
2. Click "Load Templates"
3. Select a template from text editor dropdown
4. Customize the tags
5. Generate
6. Prompt Builder combines tags into coherent prompt

EXAMPLE (Vizdev Template):
# Subject:
ancient temple ruins

# Style:
concept art, matte painting, visual development art

# Details:
overgrown vegetation, atmospheric perspective

# Environment:
misty jungle landscape

# Mood:
mysterious, ancient, abandoned

# Camera:
wide-angle establishing shot

# Lighting:
soft morning light filtering through fog

# Negative Prompt:
photorealistic, modern, cluttered

RESULT:
"concept art, matte painting, visual development art of ancient temple ruins 
with overgrown vegetation, atmospheric perspective, in misty jungle landscape. 
mysterious, ancient, abandoned atmosphere. wide-angle establishing shot 
perspective; lit by soft morning light filtering through fog."


7.3 INFLUENCE SLIDERS
----------------------

LOCATION: Alt+W → BOTTOM → Influences section

THREE SLIDERS:

SILHOUETTE (Canny Strength):
• Controls: Canny edge detection strength
• Range: 0.0 (no edges) to 1.0 (strong edges)
• Default: 0.5
• Effect: How much AI follows your scene's edges
• Use high (0.7-1.0) for: Precise geometry matching
• Use low (0.0-0.3) for: Loose interpretation

DEPTH (Depth Strength):
• Controls: Depth map influence
• Range: 0.0 (no depth) to 1.0 (strong depth)
• Default: 0.5
• Effect: How much AI respects your scene's depth
• Use high (0.7-1.0) for: Accurate spatial relationships
• Use low (0.0-0.3) for: Flat, graphic style

INFLUENCE (Texture Control):
• Controls: How much render to keep in img2img
• Range: 0.0 (full AI) to 1.0 (keep render)
• Default: 0.25 (75% AI, 25% render)
• Effect: Balance between render and AI generation
• Use high (0.7-1.0) for: Subtle enhancement, keep render
• Use low (0.0-0.3) for: Creative transformation

INTERACTION:
These sliders work together:
• High Silhouette + High Depth = Precise, geometric
• Low Silhouette + Low Depth = Loose, artistic
• High Influence = Render-based (use Detailed quality)
• Low Influence = AI-based (use Fast quality)


7.4 RENDER QUALITY (Fast/Detailed)
-----------------------------------

LOCATION: Alt+W → BOTTOM → Render Quality

TWO OPTIONS:

FAST (Workbench):
• Render time: ~0.1 seconds
• Quality: Preview quality
• Best for: Quick iterations, low Influence values
• Use when: Influence < 0.5 (AI does most work)

DETAILED (EEVEE Next):
• Render time: ~1-3 seconds
• Quality: High quality with lighting
• Best for: Final renders, high Influence values
• Use when: Influence > 0.5 (keeping most of render)

CHOOSING:
• Influence 0.0-0.3 → Use Fast
• Influence 0.4-0.6 → Either works
• Influence 0.7-1.0 → Use Detailed

NOTE: Style Engine does NOT change your scene's render engine.
This setting only affects the render sent to AI.


7.5 STEPS CONTROL
------------------

LOCATION: Alt+W → BOTTOM → Steps

WHAT IT CONTROLS:
Number of sampling steps for AI generation.

RANGE: 15-30 steps

GUIDE:
• 15 steps: Fast, good quality (default)
• 20 steps: Better quality, slightly slower
• 25 steps: High quality, slower
• 30 steps: Maximum quality, slowest

RULE OF THUMB:
• Quick iterations: 15 steps
• Final renders: 20-25 steps
• Maximum quality: 30 steps

TIME IMPACT:
• 15 steps: ~15-20 seconds
• 20 steps: ~20-25 seconds
• 25 steps: ~25-30 seconds
• 30 steps: ~30-40 seconds

8.2 COMPOSITION (COMP)
-----------------------

8.5 WEIGHT CONTROLS
--------------------

TWO LEVELS OF CONTROL:

GLOBAL STRENGTH:
• Affects all images in that mode
• Located at top of each section
• Range: 0.0-1.0
• Default: Varies by mode

INDIVIDUAL WEIGHTS:
• Per-image control
• Located under each thumbnail
• Range: 0.0-1.0
• Default: 1.0 (when image loaded)

HOW THEY INTERACT:
Final influence = Global Strength × Individual Weight

EXAMPLE:
• Global Strength: 0.8
• ST1 Weight: 1.0
• ST2 Weight: 0.5
• Result:
  - ST1 influence: 0.8 × 1.0 = 0.8
  - ST2 influence: 0.8 × 0.5 = 0.4

11.2 ARCHIVAL MATERIALS
------------------------

WHAT ARE THEY:
Unique materials created for each projection that never change.

NAMING:
• iteration_000 (first projection)
• iteration_001 (second projection)
• iteration_002 (third projection)
• etc.

WHY ARCHIVAL:
• Textures frozen in time
• Won't update when you generate new images
• Each projection is independent
• Can mix multiple generations in one scene

MATERIAL SETUP:
• Principled BSDF shader
• Roughness: 1.0 (matte finish)
• Base Color: Connected to texture
• Specular Tint: Connected to texture (prevents white IOR look)

IMAGE STORAGE:
• Packed into .blend file (embedded)
• Saved to iterations/ folder (external backup)
• Named: iteration_000.png, iteration_001.png, etc.


11.3 ITERATION SYSTEM
----------------------

WHAT IT TRACKS:
Every texture projection creates an iteration.

ITERATION COMPONENTS:
1. Material: iteration_000
2. Image (packed): iteration_000.png (in .blend)
3. Image (external): iteration_000.png (in iterations/ folder)
4. 3D Snapshot: Iteration_000 (optional, in "Iterations" collection)

NUMBERING:
• Sequential: 000, 001, 002, etc.
• Automatic: Finds next available number
• Persistent: Numbers don't reuse

FINDING ITERATIONS:
• Materials: Shader Editor → Material dropdown
• Images (packed): UV/Image Editor → Image dropdown
• Images (external): File browser → iterations/ folder
• 3D Snapshots: Outliner → "Iterations" collection


11.4 MULTI-OBJECT PROJECTION
-----------------------------

PROJECTING ON MULTIPLE OBJECTS:

STEP 1: Select All Objects
• Select first object
• Shift+Click other objects
• Or: Box select (B key)
• Or: Select all (A key) and deselect unwanted

STEP 2: Position View
• Rotate view to desired projection angle
• Zoom to frame objects
• This is your projection direction

STEP 3: Project
• Alt+W → Project on Object
• All selected objects get the same material
• UVs projected from your view

RESULT:
• All objects share iteration_xxx material
• All have same texture
• All projected from same angle

TIPS:
• Works best with objects facing same direction
• For different angles, project separately
• All objects must be mesh type
• Non-mesh objects ignored

SOLUTION:
• ◀ disabled: You're at oldest generation
• ▶ disabled: You're at latest generation
• Generate more images to enable navigation

ISSUE: Preview images not downloading
SOLUTION:
• Check "Download Preview Images" is enabled
• Verify you're using GCS mode (not RunComfy)
• Check that StyleEngineTexture.json workflow is loaded
• Verify ComfyUI has SaveImage nodes for canny/depth

16.4 GLOSSARY
--------------

AI CAMERA:
The camera object created by Style Engine that displays AI-generated images
as its background.

ARCHIVAL MATERIAL:
A unique material (iteration_xxx) that contains a frozen copy of an AI 
texture, ensuring it never changes when new images are generated.

BACKEND:
The service used for AI generation (GCS, RunComfy, or Local).

CANNY:
Edge detection algorithm that identifies contours and silhouettes in images.

COMBINED VIEW:
The default visualization showing the final AI-generated image.

CONTROLNET:
AI technique that uses edge/depth maps to guide image generation while 
maintaining structure.

CURRENT_AI.PNG:
The active AI image displayed in the camera view and used for projection.

DEPTH MAP:
Grayscale image showing distance from camera (bright=near, dark=far).

GENERATION:
A single AI-generated image saved to the generations/ folder.

GENERATION BROWSER:
UI feature that allows navigation through saved generations using ◀ ▶ buttons.

IMG2IMG:
Image-to-image workflow where AI starts from an existing image (your render)
rather than generating from scratch.

INFLUENCE:
Control slider that determines how much of your render is kept (1.0) vs how
much AI generation is applied (0.0).

IPADAPTER:
AI technique that uses reference images to influence style, composition, or
other aspects of generation.

ITERATION:
A projected texture with its associated material and optional 3D snapshot.

PER-PROJECT LIBRARY:
Folder structure (YourProject_styleengine/) that stores all images and data
for a specific .blend file.

PROJECT LIBRARY:
See "Per-Project Library"
