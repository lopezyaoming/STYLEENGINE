# Style Engine - Quick Start Guide

## 🚀 Get Started in 3 Minutes

### Step 1: Install (30 seconds)

**Option A: Development Mode (Recommended)**
```bash
# Right-click and "Run as Administrator"
setup_dev_addon.bat
```

**Option B: Manual Install**
1. Copy `scripts/addons/styleengine` folder
2. Paste into: `%APPDATA%\Blender Foundation\Blender\4.5\scripts\addons\`

### Step 2: Enable (30 seconds)

1. Open Blender
2. Edit → Preferences → Add-ons
3. Search: "Style Engine"
4. ✅ Check the box to enable

### Step 3: Setup Workspace (30 seconds)

1. Press `N` in 3D Viewport
2. Click "Style Engine" tab
3. Position your view where you want
4. Click **"Setup Workspace"** button

### Step 4: Verify (30 seconds)

You should now see:
- ✅ Two viewports (left modeling, right camera)
- ✅ "AI" workspace tab at top
- ✅ Camera view on right with blue background
- ✅ `ai_camera` in outliner

## 🎯 You're Done!
