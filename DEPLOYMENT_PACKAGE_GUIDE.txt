QUICK STEPS TO PACKAGE THE ADDON
---------------------------------------------------

Option 1: ZIP FILE (Recommended for Distribution)
---------------------------------------------------

1. Navigate to:
   C:\Coding\STYLEENGINE\scripts\addons\

2. Create a ZIP file containing the 'styleengine' folder:
   - Right-click on 'styleengine' folder
   - Send to → Compressed (zipped) folder
   - Name it: styleengine.zip

3. Share the ZIP file with users
   - They install via: Edit → Preferences → Add-ons → Install


Option 2: FOLDER COPY (Development/Internal Use)
---------------------------------------------------

1. Simply copy the entire folder:
   C:\Coding\STYLEENGINE\scripts\addons\styleengine\

2. Users paste it into their Blender addons folder:
   Windows: C:\Users\[Name]\AppData\Roaming\Blender Foundation\Blender\[Version]\scripts\addons\
   macOS:   ~/Library/Application Support/Blender/[Version]/scripts/addons/
   Linux:   ~/.config/blender/[Version]/scripts/addons/
