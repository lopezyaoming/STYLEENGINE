# TIPS FOR CREATING YOUR OWN:
# ================================================================
# 
# 1. START WITH SUBJECT - What's the main focus?
# 2. DEFINE STYLE - Art medium, technique, quality
# 3. ADD DETAILS - Specific features, actions, objects
# 4. SET ENVIRONMENT - Where is this happening?
# 5. CHOOSE MOOD - What feeling should it evoke?
# 6. PICK CAMERA - What angle/perspective?
# 7. DESCRIBE LIGHTING - How is it lit?
# 8. NEGATIVE PROMPT - What to avoid
