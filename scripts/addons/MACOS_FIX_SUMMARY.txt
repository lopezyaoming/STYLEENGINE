ISSUE RESOLVED:
----------------
Error: "No module named 'styleengine\__init__.ui_panel'; 
       'styleengine\__init__' is not a package"

This error occurred on macOS Blender 4.5+ during addon installation.

ROOT CAUSE:
-----------
macOS Blender has stricter Python import requirements. The previous
importlib fallback strategy didn't work because it still used relative
imports (with dot notation) which failed during installation.

SOLUTION APPLIED:
-----------------
Changed the import fallback from:
  ❌ importlib.import_module(".ui_panel", package=__name__)
  ❌ import ui_panel  (absolute import - still failed)
  
To:
  ✅ importlib.util.spec_from_file_location() - Direct file path loading

This is the MOST ROBUST method for strict import systems.

HOW IT WORKS:
-------------
1. Try relative imports first (standard Python packages)
2. If that fails, load each module directly by its file path
3. Use importlib.util.spec_from_file_location() to create module specs
4. Register modules in sys.modules with proper package names
5. Execute modules using spec.loader.exec_module()

This bypasses all import system restrictions entirely!

CODE STRUCTURE:
---------------

import bpy
import sys
import os

# Get addon directory for robust imports
addon_dir = os.path.dirname(os.path.abspath(__file__))

# Try relative imports first (works on most systems)
try:
    from . import ui_panel
    from . import prefs
    # ... other modules
except (ImportError, ValueError) as e:
    # BULLETPROOF FALLBACK: Load modules by file path
    import importlib.util
    
    def load_module(module_name):
        """Load a module by its file path."""
        file_path = os.path.join(addon_dir, f"{module_name}.py")
        spec = importlib.util.spec_from_file_location(module_name, file_path)
        module = importlib.util.module_from_spec(spec)
        sys.modules[f"styleengine.{module_name}"] = module
        spec.loader.exec_module(module)
        return module
    
    ui_panel = load_module("ui_panel")
    prefs = load_module("prefs")
    # ... other modules
