VERIFY ZIP STRUCTURE:
================================================================

Before installing, you can verify the ZIP structure:

1. Unzip styleengine.zip to a folder
2. Check the structure:
   ```
   styleengine/              ← This folder MUST be at root
   ├── __init__.py
   ├── utils.py
   ├── ui_panel.py
   ├── prefs.py
   ├── workspace_setup.py
   ├── runcomfy_client.py
   ├── runcomfy_deployment.py
   ├── runcomfy_polling.py
   └── README.md
   ```

3. If you see files DIRECTLY in the root (without styleengine folder),
   the ZIP is packaged incorrectly!

COMMON ISSUES:
================================================================

ISSUE: addon_dir = "/Users/.../addons" (missing /styleengine)
CAUSE: ZIP was created with files at root, not in subfolder
FIX:   Repackage ZIP with proper structure

ISSUE: "No such file or directory: '.../addons/utils.py'"
CAUSE: Same as above - missing styleengine subfolder
FIX:   Verify ZIP structure

ISSUE: "ImportError: cannot import name 'X' from 'styleengine.Y'"
CAUSE: Circular import or missing dependency
FIX:   Load modules in correct order (utils first)
