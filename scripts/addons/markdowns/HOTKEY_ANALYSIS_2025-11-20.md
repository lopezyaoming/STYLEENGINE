# Hotkey Analysis for Style Engine Pie Menu
**Date:** November 20, 2025

## ❌ Tested and Failed

### Alt+Shift+E
- **Issue:** Obnoxious to use (3 keys, awkward)
- **Conflicts:** None
- **Verdict:** Works but poor UX

### Alt+Q
- **Issue:** "No target object to transfer the mode to"
- **Conflicts:** Blender's "Transfer Mode" operator
- **Verdict:** CONFLICT - Cannot use

## 🔍 Analysis of Available Keys

### HEAVYPOLY Uses (Alt+):
- Alt+N - Revert without prompt
- Alt+U - Screencast keys
- Alt+Z - Select more (mesh mode)
- Alt+B - Bevel weight (mesh mode)
- Alt+Space - Inset (mesh mode)
- Ctrl+Shift+Alt+Space - Areas pie

### Blender Default Uses (Alt+):
- Alt+A - Animation play/stop (timeline)
- Alt+Q - Transfer mode
- Alt+H - Hide unselected
- Alt+G - Clear location
- Alt+R - Clear rotation
- Alt+S - Clear scale
- Alt+D - Duplicate linked
- Alt+M - Merge menu (mesh)

## ✅ Potentially Free Combinations

### Option 1: **Alt+E** ⭐ RECOMMENDED
- **Keys:** 2 (Alt + E)
- **Ergonomics:** Excellent (E is easy to reach)
- **Blender:** E alone is Extrude, Shift+E is Extrude menu
- **HEAVYPOLY:** Uses E alone, Ctrl+Shift+E for bevel
- **Alt+E:** APPEARS FREE
- **Memorability:** E = "Engine" (Style Engine)

### Option 2: **Ctrl+E**
- **Keys:** 2 (Ctrl + E)
- **Ergonomics:** Good
- **Blender:** E alone is Extrude
- **Ctrl+E:** Edge menu in mesh mode (might conflict)
- **Verdict:** Possible conflict

### Option 3: **Alt+W**
- **Keys:** 2 (Alt + W)
- **Ergonomics:** Good (W is WASD)
- **Blender:** W alone is Select menu
- **Alt+W:** Appears free
- **Memorability:** W = "Workflow"

### Option 4: **Alt+X**
- **Keys:** 2 (Alt + X)
- **Ergonomics:** Good
- **Blender:** X alone is Delete
- **HEAVYPOLY:** Shift+X is Symmetry pie
- **Alt+X:** Appears free
- **Memorability:** X = "eXecute" generation

### Option 5: **Alt+C**
- **Keys:** 2 (Alt + C)
- **Ergonomics:** Good (C is near WASD)
- **Blender:** C alone is Circle select
- **Alt+C:** Appears free
- **Memorability:** C = "Create" AI image

### Option 6: **Shift+Space**
- **Keys:** 2 (Shift + Space)
- **Ergonomics:** Excellent (spacebar is huge)
- **Blender:** Space alone is search
- **HEAVYPOLY:** Space alone is translate, Shift+Space is extrude
- **Verdict:** CONFLICT with HEAVYPOLY

## 🎯 Top Recommendation: **Alt+E**

### Why Alt+E?
1. **Only 2 keys** - Simple and fast
2. **Ergonomic** - E is right under your middle finger
3. **No conflicts** - Neither Blender nor HEAVYPOLY use Alt+E
4. **Memorable** - E = "Engine" (Style Engine)
5. **Logical** - E is already associated with modeling (Extrude)
