# Generation Browser - Quick Guide
**Date:** November 21, 2025

---

## 🎯 What Is It?

Navigate through your saved AI generations and choose which one to project onto objects.

---

## 🎮 How to Use

### Step 1: Generate Multiple Images
```
1. Alt+W → Generate Image
2. Wait for completion
3. Repeat 3-5 times
→ All saved to generations/ folder
```

### Step 2: Navigate
```
1. Alt+W → Open pie menu
2. Look at RIGHT section (Visualization)
3. See: ◀  Latest (5)  ▶
4. Click ◀ to go to older generations
5. Click ▶ to go to newer generations
```

### Step 3: Project
```
1. Navigate to desired generation
2. Select object(s)
3. Alt+W → Project on Object
→ Object gets that generation's texture!
```

---

## 📊 Display

### What You See:
- **"Latest (5)"** - At newest generation (5 total)
- **"4/5"** - At generation 4 of 5
- **"3/5"** - At generation 3 of 5
- **"1/5"** - At oldest generation

### Button States:
- **◀ Disabled** - Can't go older (at oldest)
- **▶ Disabled** - Can't go newer (at latest)
- **Both Enabled** - Can navigate both directions

## 🎨 Remix Workflow

### Build Complex Scenes:

```
Generate Style A → Navigate to it → Project on Object 1
Generate Style B → Navigate to it → Project on Object 2
Generate Style C → Navigate to it → Project on Object 3

Result: Three different AI styles in one scene!
```

---

## 💡 Pro Tips

### 1. **Generate First, Navigate Later**
```
Generate 5-10 variations quickly
→ Then navigate and choose best
→ Faster than deciding each time
```

### 2. **Mix and Match**
```
Generate photorealistic background
Generate painterly characters
→ Navigate between them
→ Project on appropriate objects
```

### 3. **Compare Before Projecting**
```
Navigate back and forth
→ Compare in camera view
→ Choose best
→ Then project
```

### 4. **Iterative Refinement**
```
Generate rough → Project on temp object
Generate refined → Navigate back to rough
Compare → Navigate to refined → Project on final
```

---

## ⚠️ Important

### What Navigation Does:
- ✅ Updates `current_ai.png` (camera view changes)
- ✅ Affects what gets projected
- ✅ Real-time, immediate update

### What It Doesn't Do:
- ❌ Doesn't change already-projected objects
- ❌ Doesn't delete generations
- ❌ Doesn't modify saved files

```
Alt+W → ◀ → ◀ → ▶ → Project on Object
│       │    │    │    └─ Project current generation
│       │    │    └────── Go forward (newer)
```
