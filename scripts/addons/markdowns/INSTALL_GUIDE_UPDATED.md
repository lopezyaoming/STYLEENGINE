## 🚀 Quick Install (3 Steps)

### 1. Download the Package
Location: `C:\Coding\STYLEENGINE\scripts\addons\styleengine.zip`  
Size: ~41 KB  

### 2. Install in Blender
```
Blender → Edit → Preferences → Add-ons
→ Click "Install from Disk..."
→ Select: styleengine.zip
→ Enable checkbox: "Style Engine"
```

### 3. Verify Installation
- Open any `.blend` file
- Look for "Style Engine" panel in 3D viewport (right sidebar, press N if hidden)
- Check default prompt includes: `[Updated: 2025-11-04 21:25]`
- If you see this timestamp, installation successful! ✅

## 📋 First Time Setup

### Step 1: Open the Panel
- Press `N` in 3D viewport to show sidebar
- Find "Style Engine" tab on the right
- If not visible, scroll tabs or check if addon is enabled

### Step 2: Configure API (Optional)
- Expand "Advanced Settings" in panel
- Enter your RunComfy API key (if using cloud generation)
- Save preferences

### Step 3: Setup Workspace
- Click **"Setup Workspace"** button
- Wait 1-2 seconds for layout to configure
- You should now see:
  - Left (75%): Modeling view
  - Top-Right (16.5%): Camera view (locked)
  - Bottom-Right (8.5%): Text editor with prompt

### Step 4: Test Generation
- Edit the prompt in the text editor (bottom-right)
- Click **"Generate AI Image"**
- Console should show: `[Style Engine] ✓ Auto-synced prompt from text editor`
- Camera view updates with AI result

## 🔄 Updating from Previous Version

### If You Already Have Style Engine Installed:

#### Option A: Clean Install (Recommended)
1. **Disable old addon**:
   - Preferences → Add-ons → Find "Style Engine"
   - Uncheck the checkbox (or click Remove)
2. **Close Blender** (important!)
3. **Restart Blender**
4. **Install new version** (see Quick Install above)
5. **Enable addon**
6. **Open your project**
7. **Re-run "Setup Workspace"** to get new layout

1. **Just install new ZIP** over the old one

## 🔍 Troubleshooting Installation

### "Style Engine tab doesn't appear"
**Solution 1**: Press `N` in 3D viewport to show sidebar  
**Solution 2**: Check if addon is enabled (Preferences → Add-ons → search "Style")  
**Solution 3**: Restart Blender after installing  

### "Setup Workspace doesn't create text editor"
**Solution 1**: Check window size (must be ≥ 1366x768)  
**Solution 2**: Check Advanced Settings → Enable Viewport Split = ON  
**Solution 3**: Manually add text editor (change any area to Text Editor type)  

### "Cannot install ZIP file"
**Solution 1**: Make sure ZIP file is NOT open in another program  
**Solution 2**: Extract ZIP and verify contents (should have `__init__.py`, etc.)  
**Solution 3**: Try installing from a different location (copy ZIP to Desktop first)  

### "ImportError: No module named..." (macOS)
**This should NOT happen anymore!** We macOS-proofed the addon.

**If it still happens**:
1. Check if you're on Blender 4.2+ (not 4.1 or older)
2. Verify the ZIP structure (run `validate_package.py` on Windows)
3. Report the issue with full error traceback

### "Addon enabled but nothing works"
**Solution**: Restart Blender! Blender caches Python modules.

### "Old buttons still showing"
**Solution**: You're running the old version. Restart Blender after installing new ZIP.

## 🆘 Getting Help

### Console Output
Always check the console for diagnostic messages:
- **Windows**: Window → Toggle System Console
- **macOS**: Terminal → Run Blender from terminal to see console
- **Linux**: Run `blender` from terminal

### Look for These Messages:
```
✅ Good:
[Style Engine] ✓ Camera view configured (top)
[Style Engine] ✓ Text editor configured (bottom)
[Style Engine] ✓ Workspace layout complete
[Style Engine] ✓ Auto-synced prompt from text editor

❌ Errors:
[Style Engine] Error splitting viewport: ...
[Style Engine] WARNING: Combined pass not found
ImportError: cannot import name '...'
```

### Common Error Messages:

**"Cannot import..."**
→ Blender version too old or addon not installed correctly

**"Camera not found"**
→ Run "Setup Workspace" first

**"No prompt found in text editor"**
→ Text editor not created; check window size or preferences

**"Generation already in progress"**
→ Wait for current generation to finish

## ⚙️ Configuration Options

### Basic (In Panel):
- **Global Prompt**: Quick edit (or use text editor)
- **Steps**: AI generation steps (default: 20)
- **Image Size**: 512x512, 768x768, or 1024x1024
- **CFG Scale**: Prompt strength (default: 7.0)

### Advanced (In Preferences → Add-ons → Style Engine):
- **API Key**: RunComfy cloud API key
- **Debug Mode**: Verbose console logging
- **Enable Viewport Split**: Auto-create layout (default: ON)
- **Enable Camera Switching**: Allow camera activation (default: ON)
- **Enable Auto-Render**: Render passes automatically (default: ON)
- **Camera Name Override**: Custom camera name (default: "AI Camera")
- **Workspace Name Override**: Custom workspace name (default: "AI")

## 🔐 Security & Privacy

### What Data is Stored?
- **Locally**: Render passes, temp files, session.json
- **In .blend file**: Prompt text, preferences, scene data
- **In Cloud** (if using RunComfy): Uploaded images and prompts

### What is NOT Stored?
- ❌ Your API key is encrypted in Blender preferences
- ❌ No telemetry or analytics sent
- ❌ No user tracking
- ❌ No automatic updates (manual install only)

### Cloud API (RunComfy):
- Images uploaded temporarily for AI processing
- Prompts sent to AI model for generation
- Results downloaded and cached locally
- Check RunComfy's privacy policy for retention details
