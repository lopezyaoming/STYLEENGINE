╔══════════════════════════════════════════════════════════════════╗
║                  TYPICAL ARTIST WORKFLOW                         ║
╚══════════════════════════════════════════════════════════════════╝

1. GENERATE IMAGE
   ├─ Alt+W → Generate Image
   ├─ Wait for completion
   └─ ✓ Camera shows final image (auto-set to COMBINED)

2. INSPECT EDGES
   ├─ Alt+W → Right → Silhouette
   ├─ Check edge detection quality
   └─ Verify important contours are captured

3. INSPECT DEPTH
   ├─ Alt+W → Right → Depth
   ├─ Check depth perception
   └─ Verify foreground/background separation

4. BACK TO FINAL
   ├─ Alt+W → Right → Combined
   └─ View final result

5. ITERATE
   ├─ Adjust scene geometry
   ├─ Alt+W → Generate Image
   └─ Repeat inspection cycle
