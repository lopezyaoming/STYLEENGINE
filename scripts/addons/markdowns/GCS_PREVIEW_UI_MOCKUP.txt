╔══════════════════════════════════════════════════════════════════╗
║                    WHEN TO USE THIS FEATURE                      ║
╚══════════════════════════════════════════════════════════════════╝

✅ ENABLE WHEN:                    ❌ KEEP DISABLED WHEN:
──────────────────────────────────────────────────────────────────
• Debugging ControlNet issues      • Production workflow (default)
• Learning how preprocessors work  • Bandwidth is limited
• Quality control checks           • Speed is priority
• Documenting your process         • You only need final image
• Verifying edge detection         • Storage concerns
• Understanding depth influence    • Fast iteration needed

║                    QUICK REFERENCE                               ║
╚══════════════════════════════════════════════════════════════════╝

📍 Location:  Edit → Preferences → Add-ons → Style Engine
🎯 Purpose:   Visual feedback on ControlNet preprocessing
💾 Storage:   Temp directory only (auto-cleanup)
⚙️ Default:   Disabled (for speed and bandwidth)
🔄 Workflow:  Requires StyleEnginePreview.json
📊 Impact:    +2 images, +2 MB, +1 second per generation
