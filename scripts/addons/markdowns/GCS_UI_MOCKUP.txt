═══════════════════════════════════════════════════════════════
                    DESIGN PHILOSOPHY
═══════════════════════════════════════════════════════════════

✓ MINIMAL      - Only 2 lines, compact box
✓ LACONIC      - "Generating: 15s" not "Generation in progress: 15 seconds elapsed"
✓ CONTEXTUAL   - Only shows when relevant (GCS mode + active/has history)
✓ COMPARATIVE  - Previous time enables user estimation
✓ INFORMATIVE  - Answers: "Is it working?" "How long?" "Faster/slower?"
✓ NON-BLOCKING - Doesn't require user interaction
✓ FAIL-SAFE    - Wrapped in try/except, never breaks UI
✓ REAL-TIME    - Updates automatically every 10s


═══════════════════════════════════════════════════════════════
                    TECHNICAL SPECS
═══════════════════════════════════════════════════════════════

Update Frequency:   Every 10 seconds (polling interval)
Display Latency:    <1ms (simple dict lookup)
Memory Overhead:    ~100 bytes (status dict)
UI Redraw Cost:     Negligible (Blender handles efficiently)
Mode Specificity:   GCS only (hidden in RunComfy mode)
Persistence:        Last time persists until Blender restart
